چی لە ئامێرەکەت دەچێتە دەرەوە

مێژوو، پەڕە و وێنەکانت لەسەر ئامێرەکەت دەمێننەوە. هیچ شتێک لەوەی دەیکەیت ناگاتە ئێمە، و هیچ تێلێمێتری، توێژینەوە یان ڕاپۆرتی تێکچوون بۆ Mozilla ناچێت. هێشتا وێبگەڕێک دەبێت لەگەڵ چەند خزمەتگوزارییەک قسە بکات، بۆیە هەموویان لێرەن.

  • ناوی ماڵپەڕەکان، بۆ Cloudflare. بۆ ڕاگرتنی ماڵپەڕی گەورەساڵان لە ئاستی تۆڕدا، وێبگەڕەکە ناوەکان لە ڕێگەی DNS ی خێزانی Cloudflare دەدۆزێتەوە، بۆیە Cloudflare ناوی ئەو ماڵپەڕانە دەبینێت کە سەردانیان دەکەیت.
  • داگرتنەکان. uBlock Origin لە addons.mozilla.org، لیستەکانی ڕاگرتنی ڕیکلام، و کۆدێکی ڤیدیۆ لە Mozilla و Cisco و Google.
  • چی نوێیە. دوای نوێکردنەوەیەک، پەڕەی دەستپێک یەکجار تێبینییەکانی ئەو وەشانە لە GitHub داوا دەکات. هیچ شتێک دەربارەی تۆ نانێردرێت.
  • ژماردنێکی بێناو، بۆ ئێمە. وێبگەڕەکە ڕۆژی جارێک خۆی دەژمێرێت: وەشانەکەی، سیستەمەکەی، ئایا Premium چالاکە و ئەو وڵاتەی داواکارییەکەی لێوە دێت (نەک ناونیشانەکەت)، بێ ناسنامە و بێ هیچ شتێک لەوەی سەردانی دەکەیت. لە ڕێکخستنەکان، لەژێر بە بێناوی بمژمێرە، بیکوژێنەرەوە.
  • کلیلی Premium، ئەگەر یەکێک بنووسیت. لەگەڵ ڕاژەکاری مۆڵەتەکەمان بە ناسنامەیەکی هەڕەمەکی دامەزراندن دەپشکنرێت، بۆ ئەوەی کلیلێک لە یەک کاتدا لەسەر 3 ئامێر کار بکات. ڕاژەکارەکە تەنها هاشی کلیل و ناسنامەی دامەزراندن هەڵدەگرێت، هەرگیز داتای گەڕانت نا. ئەگەر ناونیشانی ئیمەیڵ بدەیت (بۆ وەرگرتنی کلیلەکەت، بۆ دیاری یان بۆ ڕاپۆرتی دایک و باوکی Family)، بۆ ئەوە بەکاردێت؛ سیاسەتی تایبەتێتی دەڵێت چی هەڵدەگیرێت.
  • هەواڵنامە. تەنها ئەگەر لە akhibrowser.com/ckb/newsletter ناو تۆمار بکەیت (یان لە کاتی پارەداندا خانەکە نیشان بکەیت) و بە ئیمەیڵ پشتڕاستی بکەیتەوە: ڕاژەکاری مۆڵەت ناونیشانەکەت، زمانەکەی و بەروارەکان هەڵدەگرێت، بۆ ناردنی ئایەتێک لە قورئان و هەواڵە نوێکان هەفتەی جارێک، و یەکجار 10% داشکاندن لەسەر Family Premium. هەر ئیمەیڵێک بەستەرێکی تێدایە بۆ وەستاندن؛ ناونیشانەکە هەرگیز هاوبەش ناکرێت.
  • شیکاری ماڵپەڕ. تا لە بانەرەکەدا ڕێگەدان دانەگریت هیچ شتێک لە Google بار ناکرێت؛ دوای ئەوە ماڵپەڕەکە Google Tag Manager بار دەکات، بۆیە Google ناونیشانی IP ی پەیوەندییەکە و زانیاری تەکنیکی داواکارییەکە وەردەگرێت. Google Analytics تەنها دوای ئەوەی لە بانەرەکەدا ڕێگەدان دادەگریت سەردان و کرتەکان (لەسەر دوگمەی داگرتن یان پلانێک) دەژمێرێت؛ تا ئەوکات هیچ کووکییەکی شیکاری دانانرێت. کاتێک دوای ڕێگەدان پلانێک دەکڕیت، ناسنامە بێناوەکەی Google Analytics ت لەگەڵ پارەدانەکە دەچێت، بۆ ئەوەی کڕینەکە (پلان و بڕ، هەرگیز ئیمەیڵ یان کلیلەکەت نا) بۆ سەردانەکە بژمێردرێت. دوای ڕێگەدان، پیکسڵی Reddit یش بار دەبێت، بۆ ئەوەی Reddit ببینێت کە سەردانێک، کرتەیەک لەسەر دوگمەی داگرتن، ناوتۆمارکردنێکی پشتڕاستکراوی هەواڵنامە یان داواکارییەک بۆ بوون بە هاوکار یان هاوبەش لە یەکێک لە ڕیکلامەکانییەوە هاتووە (Reddit کووکی خۆی بۆ ئەمە دادەنێت). ئەگەر لە ڕیکلامێکی Reddit ەوە هاتبیت و دوای ڕێگەدان کرتە لە دوگمەی داگرتن بکەیت یان پلانێک بکڕیت، ڕاژەکاری مۆڵەت بە Reddit دەڵێت کە ڕیکلامەکە بووەتە هۆی داگرتن (ناسنامەی کرتەی Reddit و فرۆشگاکە، لەگەڵ ناونیشانی IP ەکەت و user agent ی وێبگەڕەکەت) یان کڕین (ناسنامەی کرتەی Reddit، بڕ و دراوی پلانەکە). هەمان شت بۆ ناوتۆمارکردنی هەواڵنامە (کاتێک پشتڕاستی دەکەیتەوە) یان داواکاری بۆ بوون بە هاوکار یان هاوبەش ڕاستە: ناسنامەی کرتەی Reddit، ناسنامەیەکی ڕووداو، ناونیشانی IP و user agent ەکەت، هەرگیز ناو یان ئیمەیڵەکەت نا. ئەگەر دوای کرتەیەکی وا ئەپی Android لە Google Play دابمەزرێنیت، بەستەری Play ناسنامەی کرتەی Reddit هەڵدەگرێت، و ئەپەکە یەکجار لەگەڵ ناسنامەیەکی هەڕەمەکی بۆ ئەو دامەزراندنە دەینێرێت بۆ ڕاژەکاری مۆڵەت، بۆ ئەوەی Reddit بتوانێت ئەو دامەزراندنانە بژمێرێت کە لە ڕیکلامەکانییەوە دێن (ناسنامەی کرتەی Reddit، ئەو ناسنامەیە، ناونیشانی IP و user agent ەکەت). کوژاندنەوەی "بە بێناوی بمژمێرە" لە ئەپەکەدا ئەمەش ڕادەگرێت. هەڵبژاردنەکەت بگۆڕە. سیاسەتی تایبەتێتی Google ببینە.
