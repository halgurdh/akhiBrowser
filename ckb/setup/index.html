ئامۆژگاری بۆ دایک و باوکان: کەلێنەکان دابخە

AkhiBrowser ئەوە دەپارێزێت کە لە AkhiBrowser دا ڕوودەدات. منداڵێک کە وێبگەڕ یان ئەپێکی تر بکاتەوە لێی تێدەپەڕێت. ئەم هەنگاوانە ئەو کەلێنانە دادەخەن، و زۆربەیان چەند خولەکێک دەخایەنن.

  • ئەکاونتی خۆی بدە بە منداڵەکەت

    لەسەر Windows، ئەکاونتێکی ئاسایی، نەک بەڕێوەبەر، بۆ ئەوەی منداڵەکەت نەتوانێت وێبگەڕی تر دابمەزرێنێت یان ڕێکخستنەکان بگۆڕێت. لەسەر Android، ئەکاونتێکی Google بۆ منداڵەکەت، کە بە Google Family Link بەڕێوە دەبرێت.

  • AkhiBrowser بکە بە وێبگەڕی بنەڕەت

    ئەوکات بەستەرەکانی ئەپەکانی تر لە AkhiBrowser دا دەکرێنەوە. Windows: Settings، Apps، Default apps. Android: Settings، Apps، Default apps، Browser app.

  • وێبگەڕەکانی تر ڕابگرە

    لەسەر Android، Chrome و هەر وێبگەڕێکی تر لە Family Link دا، لەژێر سنووری ئەپەکانی منداڵەکەت ڕابگرە. لەسەر Windows، ئەو وێبگەڕانەی منداڵەکەت پێویستی پێیان نییە لاببە، و ئەوانی تر لە Microsoft Family Safety دا، لەژێر ئەپ و یارییەکان ڕابگرە.

  • هەموو مۆبایلەکە یان تۆڕی ماڵەوە فلتەر بکە

    AkhiBrowser ماڵپەڕەکان لە ڕێگەی DNS ی خێزانی Cloudflare دەدۆزێتەوە. بۆ هەموو ئەپێکیش بەکاری بهێنە: لەسەر Android، Private DNS لەسەر family.cloudflare-dns.com دابنێ (Settings، Network and internet؛ ڕێگاکە لە هەر مۆبایلێکدا کەمێک جیاوازە). لەسەر ڕاوتەرەکەت، ڕاژەکارەکانی DNS لەسەر 1.1.1.3 و 1.0.0.3 دابنێ، بۆ هەموو ئامێرێکی Wi-Fi ەکەت.

  • PIN ی دایک و باوک دابنێ

    لە ڕێکخستنەکانی AkhiBrowser دا PIN ی دایک و باوک دابنێ، بۆ ئەوەی پاراستنەکان بەبێ تۆ نەکوژێنرێنەوە.

  • لەگەڵ منداڵەکەت قسە بکە

    هیچ فلتەرێک هەموو شتێک ناگرێت. بە منداڵەکەت بڵێ بۆچی ئەم یاسایانە هەن، و هەمیشە دەتوانێت بێتە لات کاتێک شتێکی هەڵە دەبینێت.
