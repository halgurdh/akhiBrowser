Apa yang keluar dari perangkatmu

Riwayat, halaman, dan gambarmu tetap di perangkatmu. Tidak ada yang kamu lakukan yang sampai ke kami, dan tidak ada telemetri, studi, atau laporan crash yang dikirim ke Mozilla. Browser tetap harus berbicara dengan beberapa layanan, jadi inilah semuanya.

  • Nama situs, ke Cloudflare. Untuk memblokir situs dewasa di tingkat jaringan, browser mencari nama lewat DNS keluarga Cloudflare, jadi Cloudflare melihat nama situs yang kamu kunjungi.
  • Unduhan. uBlock Origin dari addons.mozilla.org, daftar blokir iklan, dan codec video dari Mozilla, Cisco, dan Google.
  • Yang baru. Setelah pembaruan, halaman awal meminta catatan rilis versi itu ke GitHub sekali. Tidak ada yang dikirim tentang dirimu.
  • Hitungan anonim, ke kami. Sekali sehari browser menghitung dirinya sendiri: versinya, sistemnya, apakah Premium aktif, dan negara asal permintaan (bukan alamatmu), tanpa ID dan tanpa apa pun yang kamu kunjungi. Matikan di pengaturan, di bawah Hitung secara anonim.
  • Kunci Premium, jika kamu memasukkannya. Kunci diperiksa dengan server lisensi kami, dengan ID instalasi acak, agar satu kunci berfungsi di 3 perangkat sekaligus. Server hanya menyimpan hash kunci dan ID instalasi, tidak pernah data jelajahmu. Jika kamu memberi alamat email (untuk menerima kuncimu, untuk hadiah, atau untuk laporan orang tua Family), email itu dipakai untuk itu; kebijakan privasi menjelaskan apa yang disimpan.
  • Buletin. Hanya jika kamu mendaftar di akhibrowser.com/id/newsletter (atau mencentang kotak saat checkout) dan mengonfirmasi lewat email: server lisensi menyimpan alamatmu, bahasanya, dan tanggalnya, untuk mengirim satu ayat Al-Qur'an dan kabar terbaru seminggu sekali, dan sekali diskon 10% untuk Family Premium. Setiap email punya tautan untuk berhenti; alamat tidak pernah dibagikan.
  • Analitik situs. Tidak ada dari Google yang dimuat sampai kamu menekan Izinkan di banner; setelah itu situs memuat Google Tag Manager, jadi Google menerima alamat IP koneksi dan informasi teknis permintaan. Google Analytics hanya menghitung kunjungan dan klik (pada tombol unduh atau paket) setelah kamu menekan Izinkan di banner; sampai saat itu tidak ada cookie analitik yang dipasang. Saat kamu membeli paket setelah mengizinkannya, ID Google Analytics anonimmu ikut ke checkout, agar pembelian (paket dan jumlah, tidak pernah email atau kuncimu) dihitung untuk kunjungan itu. Setelah kamu mengizinkannya, piksel Reddit juga dimuat, agar Reddit bisa melihat bahwa kunjungan, klik tombol unduh, pendaftaran buletin yang dikonfirmasi, atau lamaran menjadi afiliasi atau mitra berasal dari salah satu iklannya (Reddit memasang cookie-nya sendiri untuk ini). Jika kamu datang dari iklan di Reddit dan, setelah mengizinkannya, mengklik tombol unduh atau membeli paket, server lisensi memberi tahu Reddit bahwa iklan itu menghasilkan unduhan (ID klik Reddit dan toko, ditambah alamat IP dan user agent browsermu) atau pembelian (ID klik Reddit, jumlah dan mata uang paket). Hal yang sama berlaku untuk mendaftar buletin (setelah kamu mengonfirmasinya) atau melamar menjadi afiliasi atau mitra: ID klik Reddit, ID peristiwa, alamat IP, dan user agent-mu, tidak pernah nama atau emailmu. Jika kamu memasang aplikasi Android dari Google Play setelah klik seperti itu, tautan Play membawa ID klik Reddit, dan aplikasi mengirimkannya sekali ke server lisensi dengan ID acak untuk instalasi itu, agar Reddit bisa menghitung instalasi dari iklannya (ID klik Reddit, ID itu, alamat IP, dan user agent-mu). Mematikan "Hitung secara anonim" di aplikasi juga menghentikan ini. Ubah pilihanmu. Lihat kebijakan privasi Google.
