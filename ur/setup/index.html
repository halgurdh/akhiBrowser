والدین کے لیے مشورے: خلا بند کریں

AkhiBrowser وہ محفوظ رکھتا ہے جو AkhiBrowser میں ہوتا ہے۔ جو بچہ کوئی دوسرا براؤزر یا ایپ کھولے وہ اس سے بچ نکلتا ہے۔ یہ اقدامات ان خلاؤں کو بند کرتے ہیں، اور زیادہ تر میں چند منٹ لگتے ہیں۔

  • اپنے بچے کو اس کا اپنا اکاؤنٹ دیں

    Windows پر ایک عام اکاؤنٹ، ایڈمنسٹریٹر نہیں، تاکہ آپ کا بچہ دوسرے براؤزر انسٹال یا ترتیبات تبدیل نہ کر سکے۔ Android پر آپ کے بچے کے لیے Google اکاؤنٹ، جو Google Family Link سے منظم ہو۔

  • AkhiBrowser کو ڈیفالٹ براؤزر بنائیں

    تب دوسری ایپس کے لنکس AkhiBrowser میں کھلتے ہیں۔ Windows: Settings، Apps، Default apps۔ Android: Settings، Apps، Default apps، Browser app۔

  • دوسرے براؤزرز بند کریں

    Android پر Chrome اور کسی بھی دوسرے براؤزر کو Family Link میں، اپنے بچے کی ایپ کی حدود کے تحت بند کریں۔ Windows پر وہ براؤزرز ان انسٹال کریں جن کی آپ کے بچے کو ضرورت نہیں، اور باقی کو Microsoft Family Safety میں، ایپس اور گیمز کے تحت بند کریں۔

  • پورا فون یا گھر کا نیٹ ورک فلٹر کریں

    AkhiBrowser سائٹس کو Cloudflare کے فیملی DNS کے ذریعے تلاش کرتا ہے۔ اسے ہر ایپ کے لیے بھی استعمال کریں: Android پر Private DNS کو family.cloudflare-dns.com پر سیٹ کریں (Settings، Network and internet؛ راستہ ہر فون میں تھوڑا مختلف ہے)۔ اپنے راؤٹر پر DNS سرورز 1.1.1.3 اور 1.0.0.3 پر سیٹ کریں، آپ کے Wi-Fi کے ہر آلے کے لیے۔

  • والدین کا PIN مقرر کریں

    AkhiBrowser کی ترتیبات میں والدین کا PIN مقرر کریں، تاکہ آپ کے بغیر تحفظات بند نہ کیے جا سکیں۔

  • اپنے بچے سے بات کریں

    کوئی فلٹر سب کچھ نہیں پکڑتا۔ اپنے بچے کو بتائیں کہ یہ اصول کیوں ہیں، اور یہ کہ جب بھی وہ کچھ غلط دیکھے تو ہمیشہ آپ کے پاس آ سکتا ہے۔
