Tips voor ouders: dicht de gaten

AkhiBrowser beschermt wat er in AkhiBrowser gebeurt. Een kind dat een andere browser of app opent, gaat eromheen. Deze stappen dichten die gaten, de meeste in een paar minuten.

  • Geef je kind een eigen account

    Op Windows een standaardaccount, geen beheerder, zodat je kind geen andere browsers kan installeren of instellingen kan wijzigen. Op Android een Google-account voor je kind, beheerd met Google Family Link.

  • Maak AkhiBrowser de standaardbrowser

    Links uit andere apps openen dan in AkhiBrowser. Windows: Instellingen, Apps, Standaard-apps. Android: Instellingen, Apps, Standaard-apps, Browser-app.

  • Blokkeer de andere browsers

    Op Android blokkeer je Chrome en elke andere browser in Family Link, bij de app-limieten van je kind. Op Windows verwijder je de browsers die je kind niet nodig heeft, en blokkeer je de rest in Microsoft Family Safety, bij apps en games.

  • Filter de hele telefoon of het thuisnetwerk

    AkhiBrowser zoekt sites op via de family-DNS van Cloudflare. Gebruik die ook voor alle apps: zet op Android Privé-DNS op family.cloudflare-dns.com (Instellingen, Netwerk en internet; het pad verschilt per telefoon). Zet op je router de DNS-servers op 1.1.1.3 en 1.0.0.3, voor elk apparaat op je wifi.

  • Stel de ouder-pincode in

    Stel in de instellingen van AkhiBrowser een ouder-pincode in, zodat de beschermingen niet zonder jou uit kunnen.

  • Praat met je kind

    Geen filter houdt alles tegen. Vertel je kind waarom deze regels er zijn, en dat het altijd bij je terecht kan als het iets verkeerds ziet.
