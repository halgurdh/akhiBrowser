Conseils aux parents : combler les failles

AkhiBrowser protège ce qui se passe dans AkhiBrowser. Un enfant qui ouvre un autre navigateur ou une autre application le contourne. Ces étapes comblent ces failles, et la plupart prennent quelques minutes.

  • Donne à ton enfant son propre compte

    Sous Windows, un compte standard, pas administrateur, pour que ton enfant ne puisse pas installer d'autres navigateurs ni changer les réglages. Sous Android, un compte Google pour ton enfant, géré avec Google Family Link.

  • Fais d'AkhiBrowser le navigateur par défaut

    Les liens des autres applications s'ouvrent alors dans AkhiBrowser. Windows : Paramètres, Applications, Applications par défaut. Android : Paramètres, Applications, Applications par défaut, Application de navigateur.

  • Bloque les autres navigateurs

    Sur Android, bloque Chrome et tout autre navigateur dans Family Link, dans les limites d'applications de ton enfant. Sous Windows, désinstalle les navigateurs dont ton enfant n'a pas besoin, et bloque le reste dans Microsoft Family Safety, sous applications et jeux.

  • Filtre tout le téléphone ou le réseau de la maison

    AkhiBrowser recherche les sites via le DNS familial de Cloudflare. Utilise-le aussi pour chaque application : sur Android, règle le DNS privé sur family.cloudflare-dns.com (Paramètres, Réseau et internet ; le chemin varie un peu selon le téléphone). Sur ton routeur, règle les serveurs DNS sur 1.1.1.3 et 1.0.0.3, pour chaque appareil de ton Wi-Fi.

  • Définis le PIN parental

    Dans les réglages d'AkhiBrowser, définis un PIN parental, pour que les protections ne puissent pas être désactivées sans toi.

  • Parle avec ton enfant

    Aucun filtre n'attrape tout. Explique à ton enfant pourquoi ces règles existent, et qu'il peut toujours venir te voir quand il voit quelque chose de mal.
